# Martyvole

Kanonický GitHub účet. Starší účet `Martyparty1988` už nepoužívám.

Dělám malé webové appky a nástroje pro sebe — eshop, přehledy práce, agenti. Repozitáře jsou soukromé.

**Živé projekty**
- **HÁČEK** — tisky na zeď, objednávky a ceník
- **prace** — mobilní přehled práce nad Google Sheets
- **marusky-chvilkomer** — z „už jedu“ na občanský čas
- **hermes-control-ui** — admin panel pro Hermes agenta
